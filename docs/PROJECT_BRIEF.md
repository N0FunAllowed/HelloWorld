# Project brief: TruckRoute

TruckRoute is a simple iOS app for planning a week's trucking loads. It targets iOS 17+ / Xcode 16+, stores data locally, and uses MapKit for routes. The current scope is one truck and a nearest-neighbor route; it does not include multi-driver dispatch, tracking, hours-of-service, backend sync, or traffic-aware optimization.

Keep this document current as scope changes. It is the compact product context for planning and review agents.
